# FinPilot

### 🚀 Live Demo

[Open FinPilot](https://finpilot-007.streamlit.app/)

**An intelligent personal finance decision-support platform that turns financial data into clear, actionable insights.**

## 💡 About FinPilot

FinPilot helps individuals understand their financial behaviour by transforming raw transaction and spending data into meaningful insights, visualizations, and prioritized recommendations.

Instead of only showing users where their money went, FinPilot helps answer:

**“What should I do next?”**

## 🎯 Target Users

* Students and young adults managing personal expenses
* Working professionals tracking spending and savings
* Individuals planning budgets and financial goals
* Personal finance beginners seeking understandable financial insights

## ✨ Key Features

* 📊 Interactive financial dashboard
* 💰 Income, expense and cash-flow analysis
* 🧾 Transaction categorization and analysis
* 📈 Spending pattern visualization
* 🔁 Recurring expense identification
* 🎯 Financial goal tracking
* ⚡ Prioritized financial recommendations
* 🔮 What-if financial simulator
* 📁 CSV/Excel financial data processing

## 🧠 How It Works

```text
Financial Data
      ↓
Data Cleaning & Processing
      ↓
Transaction & Spending Analysis
      ↓
Financial Indicators
      ↓
Insight Generation
      ↓
Prioritized Recommendations
      ↓
What-If Simulation
```

## 🔍 Insights Generated

FinPilot analyzes signals such as:

* Spending behaviour
* Income vs. expenses
* Category-wise expenses
* Recurring commitments
* Savings patterns
* Cash-flow trends
* Financial goals

These signals are converted into explainable actions such as reducing unnecessary recurring expenses, adjusting spending, prioritizing savings, or planning around upcoming commitments.

## 🛠️ Tech Stack

**Language:** Python
**Framework:** Streamlit
**Data Processing:** Pandas, NumPy
**Visualization:** Plotly
**Excel Processing:** OpenPyXL

## 📊 Data Sources

FinPilot uses financial transaction and personal finance datasets for analysis and testing, including:

* Personal transaction data
* Indian personal finance and spending behaviour data

The datasets support analysis of transaction patterns, income, expenses, savings, spending categories, and financial goals.
